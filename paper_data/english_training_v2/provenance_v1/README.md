# 英文补训候选数据 v1

**状态：仅准备候选，尚未训练；是否使用由独立英文开发集诊断决定。**

这批数据由本地英文教材 *Introduction to Oceanography* 的原文直接撰写，作者 Paul Webb，CC BY 4.0（部分内容另署 Steven Earle 等来源）。不使用 Pirá 的问题、参考答案或支撑文本，也没有把既有中文候选测试题翻译后称为新题。

## 规模与内容

| 类型 | 示例数 | 用途 |
|---|---:|---|
| `closed_book` | 60 | 英文简洁知识回答，无资料时不造引用 |
| `grounded` | 180 | 原文回答、相关／无关片段混合、不同问题表达及精确引用编号 |
| `insufficient_evidence` | 60 | 资料与问题无关时明确说明材料不足 |
| 合计 | 300 | **60个知识 family，每 family 5种任务格式** |

不能把300个格式示例写成300个独立知识点或独立评测题。这里是训练候选，不能作为这次训练后的独立效果证明。

有证据示例交替使用 `[DOC1]`、实际提供的 `WEBB_p...` 及 `[SRC_F...]` 编号；混合资料示例交替放置相关片段的位置。回答引用实际提供的支持片段，避免始终记住固定引用编号。证据不足示例仅说明给定材料没有回答所需信息，并不声称问题在现实中没有答案。

## 文件

- `facts.tsv`：直接根据英文教材撰写的60个事实、两种英文问法、简短答案和可定位锚点。
- `source_facts_60.jsonl`：提取后的逐事实证据、PDF页码及原文窗口ID。
- `candidates_300.jsonl`：全部300条候选，包含标准 `messages` 和来源元数据。
- `train_candidates_240.jsonl`：可选训练划分，48个 family、240条。
- `validation_candidates_60.jsonl`：可选训练过程验证划分，另12个 family、60条。
- `family_split.json`：冻结的划分规则及 family 清单。
- `source_anchor_and_expert_review.csv`：来源锚点核验及人工审核表；专家栏全部留空。
- `system_prompt.txt`：与英文开放问答评测 `OPEN_SYSTEM` 完全相同的系统提示词。
- `manifest.json`：来源哈希、类型计数、长度核验和限制说明。
- `prepare_candidates.py`：复现脚本，仅提取教材、组合示例和载入本地 tokenizer，不载入模型、不启动训练。

可选240／60划分按知识 family 和教材小节分离，相关、无关的所给原文小节也不跨划分。两边仍来自同一本教材，不能称为完整文档独立。外部Pirá开发集和正式测试集均不在其中。

## 已完成的核验

每个事实的起止锚点均定位成功，提取片段与对应PDF页逐字匹配。页码为 **PDF从1开始的页码**，不是书内印刷页码。每条训练答案的引用均属于该条实际提供的资料，闭卷答案无引用。按本地Qwen3 tokenizer的完整 system＋user＋assistant 模板计数，无样本超过1024 token，也没有截断。

这里的本地检查包括AI作者对答案与片段的核对，不等于老师或专家批准。科学正确性、表达适当性及无关片段是否足够无关，仍可在审核表中独立复核。未使用教材中有关声速的密度因果简化、内核质量比例错误或旧气候速率统计。

## 使用顺序

1. 先完成英文开发集四组诊断，判断是否需要补训。
2. 若需要补训，先审核来源及答案，再决定使用哪个候选划分。
3. 训练器只读取每条的 `messages`。**不得把 provenance、类型标签或审核元数据拼入模型输入。**
4. 保留旧适配器，补训结果另存，按开发集选择是否采用。
5. 正式测试前冻结模型和评测设置。

这些示例较短、来源单一，不覆盖Pirá全部油气工程和研究摘要问答范围，也不能保证补训必然提升。教材与Pirá文章来源不同，但一般海洋概念可能相同；旧适配器来源和基座预训练未知，不能据此宣称绝对无污染。此前中文教材候选评测使用过同一本书，补训后不能再把它当未见来源测试。

## 2026年10月17日语义复核修订

AI作者逐组重读了60个事实的题目、答案和精确原文，以及60组无关资料配对。16个family修改了事实表措辞或来源锚点，具体前后文本保存在 `revision_history/semantic_review_2026-10-17.json`；初版事实与manifest也保留在该目录。它是AI来源复核，**不是老师或专家认证**。

- F014只讨论教材中的火山海山案例，不再把所有海山都定义为火山。
- F003、F041、F059补全原文句尾；F040补足Langmuir指代；F045改用直接讲大陆／海底地形影响潮汐的原文，避开原教材有关每天同一时刻高潮的错误简化。
- F035避免把泛称热带气旋误写成特定强度的“tropical storm”；F033、F037、F046分别明确水平运动、理想Ekman模型及潮汐日条件。
- F024、F052、F058删除不适用于另一种问法的Yes／No开头。F058不再引用短片段未直接解释的热膨胀机制，只陈述该片段支持的“海水变暖可在无新增陆冰融水时升高海平面”。
- 所有带资料正例与负例使用完全相同的“只根据给定资料回答”约束。负例只说明**这一段材料不足以支持回答**，保留60条闭卷正常回答，避免训练为“模型不知道这些常识”。

复核未发现60段配对无关材料能直接回答相应目标题。F019／F049的“溶解气体”与“固体沉淀”有词汇联系，但缺少对方问题需要的信息，已在记录中特别提示供人工复核。没有据此填入专家评分。

修订后300条完整聊天模板长度为158—452 token，平均271.59，0截断；240／60划分与全部哈希已更新。该长度是本地tokenizer计数，不是训练效果或模型成绩。

复现准备过程：

```powershell
.venv/Scripts/python.exe paper_data/english_training_v1/prepare_candidates.py
```
