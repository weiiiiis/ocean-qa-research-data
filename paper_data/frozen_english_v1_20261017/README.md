# Frozen English experiment v1

Model, prompt, BM25, parsing, masks and human-review sampling were fixed before the first official model generation. All four conditions use the same task prompts and generation settings. Official test data will not be used for tuning.

Expert scores remain pending. Lexical F1 and source-ID validity are automatic diagnostics, not factual accuracy or citation entailment. See freeze_manifest.json for exact hashes and known development defects.
