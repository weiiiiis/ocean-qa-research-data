# 正式输出前的本地评价计划

日期：2026-10-17（Asia/Shanghai）。本目录仅包含预先选择的待评题、原始参考、支撑文本定位信息及评价规则，**未读取或生成任何模型答案，也未读取开发模型成绩**。这是本地计划记录，不是OSF注册、外部预注册或专家批准；人工评分仍待真实评审完成。

## 固定40道双人评审题

从227道官方开放题中，原始`answer_in_text==1`的206题进入抽样池：corpus 1有162题，corpus 2有44题。

- 随机种子固定为`20261017`，使用同一个Python `random.Random`实例。
- 用最大余数法按两个corpus的题量比例分配40个名额：corpus 1抽31题，corpus 2抽9题；余数并列时按corpus编号升序。
- 各corpus按编号升序处理；将`source_group`字符串排序后随机打乱，抽取对应数量的来源组。
- 每个抽中来源组内按`original_id`排序，再随机抽1题。此次共40题，40个不同的原始来源组；未从同组补抽第二题。

这属于按corpus分层、优先平衡来源的随机抽样，题目并非等概率简单随机样本。corpus 2的9个组只是9个支撑片段ID，不能当成9篇独立文档。保守来源敏感性中，这些未解析片段统一归入`PIRA-UNRESOLVED-CORPUS2`。

抽样不依据任何模型回答、F1、引用表现或其他模型分数。所有抽样步骤、输入／输出哈希、Python版本及选中ID已保存于manifest.json。后续不能因为某题结果不好而替换题目。

## 另外21题的参考适用性复核

原始`answer_in_text==0`的10题及未标注的11题，单独列入参考／资料充分性复核清单。**这些标签不构成拒答金标准**：需要真实评审核查问题是否清楚、参考是否适用、实际资料是否充分；保持官方标签与参考不变，另存任何人工判断。

21题仍属于完整227题主结果；它们没有因为标签问题被静默删除。

## 自动评价规则

### 统一题目集合

1. **主结果：完整官方227题。**
2. **固定敏感性：225题。** 同时排除原始ID`A1329`、`B2585`，基于既有旧SFT筛查标记，不表示这两题已确认为重复或污染。
3. **资料标注子集：206题。** 仅原始`answer_in_text==1`，作为预先确定的副结果。

开放题与选择题使用同一`original_id`映射上述集合。各条件分母及缺失回答必须单独报告，不能把缺失当0分，也不能只报告较好看的子集。

### 选择题

统一以开头选项准确率作主项，并分开报告严格格式准确率和无效格式率。开头规则为：去除可选的前导空白后，必须是单个大写A—E，后接结尾、空白或计划中列明的标点；不能搜索回答中间的字母，也不能把`Answer`单词的A当选项。实际正则见manifest.json与prepare_plan.py。

- `A`：开头提取有效，严格格式有效。
- `A. because ...`：开头提取有效，严格格式无效。
- `Answer: A`、`**A**`、小写`a`：本计划的开头提取无效，严格格式也无效。

提取无效按选择题答错，同时单列其比例。严格格式仅允许首尾去空白后单个大写A—E，不接受解释后缀。

### 开放问答

- 自动主项：移除模型答案中可识别的方括号来源编号标记后，使用SQuAD式英文规范化，对**原始参考答案**计算Token F1。
- raw F1敏感性：保持同一原始参考，不删除模型答案中的引用标记。
- 发布的其他参考只能作为另列的敏感性结果，不能假设其语义等价已经专家验证。

EM／F1均为文本重合度，不是事实准确率、完整性或证据支持率。编号能解析也不证明它支持陈述。

### 来源相关性与不确定性

主统计按已有`source_group`作来源组配对bootstrap，2000次、种子`20261017`；主要差值为“微调＋RAG减基座＋RAG”，其他差值作为次要／探索性分析。

另重复`source_group_conservative`的分组敏感性：将所有未解析corpus 2片段合并到一个保守来源组。分组变化不改变均值，但可改变区间；既有片段分组不能冒充真正文档独立。没有被重叠扫描标记的题，也不证明基座预训练或历史SFT未见过。

## 两位真实专家的独立评分

实际模型答案产生后，才为固定40题的四个条件制作匿名材料。每位评审独立评价160条回答；RAG证据评价适用于其中80条。独立随机化匿名编号，模型映射单独保存，不发送给评审。内容和语气仍可能暴露模型行为，须承认盲法不完美。

每条回答分别评价：

- **事实正确性0—4**：0错误／缺失，1重大错误，2正误混合／部分正确，3基本正确但有小问题，4回答正确。
- **关键内容完整性0—4**：0未回答，1主要内容遗漏，2部分覆盖，3覆盖大部分必要点，4覆盖全部必要点。
- **证据支持0—4（RAG）**：依据实际提供资料判断，0不支持／矛盾，1大多不支持，2混合，3大多支持，4充分支持。无RAG答案记不适用，不能填0。
- **引用计数（RAG）**：引用链接总数、确有证据支持的链接数、需要引用的陈述数、获得有效支持引用的陈述数。

质量材料可去掉来源标记以降低条件暴露，证据材料必须保留原始答案及实际资料。两位评审先独立评分，再另记分歧讨论或裁决，不能覆盖初评。未评条目保持空白／pending，不能用F1或编号解析率自动填成人工分。

### 不足说明与回答完成度分开评价

40题的原始标注均为`answer_in_text=1`，但实际检索窗口可能漏掉必要内容。**质量材料按问题要求的事实和关键要点评价是否答完**；缺失答案或只说“资料不足”不能算完整正确答案。纯粹拒答且没有覆盖所求事实，不具有关键要点完整性；由真实评审依规则评分，程序不自动填分。

**证据材料单独判断忠实性**：若实际提供资料确实不足，恰当、有限定的不足说明可以被判为忠实；这不等于回答已经完成，也不提高其事实任务完成度或完整性。如果所需证据已经提供，笼统拒答也不能自动得到高忠实分。三个维度分别报告，不能让“总拒答”凭忠实性获得高整体答案质量评价。

上述区分不把另外21题设成拒答金标准，不修改其官方标签或原始参考，参考适用性仍由人工另行复核。

如发现参考有疑问，另行标记并记录理由；不能针对正式模型结果静默修复标签或临时挑选排除题。
